OOD/OSR Paper Notes

Summaries and feature comparison of OOD/OSR algorithms classified into 4 categories: (1) Classification-based (2) Distance-based (3) Density-based (4) Reconstrction-based

Papers

[1] Out-of-Distribution Detection with Deep Nearest Neighbors
ICML 2022 Citations: 1,121 (as on date 08/15/2026) Category: OOD, Distance-based
Paper link

Most prior distance-based OOD detection methods assume the ID feature embeddings for each class follow a Gaussian distribution, and use Mahalanobis distance to the nearest class centroid to flag OOD samples. But this assumption often doesn't hold in practice, which makes Mahalanobis distance unreliable for OOD detection. It's also computationally expensive, since it requires inverting a covariance matrix.

In this paper, a non-parametric approach leveraging KNN is proposed, which makes no assumption about the shape of the feature distribution. After training a neural network encoder, both training and test embeddings are L2-normalized, and a test sample is flagged as OOD if its distance to the k-th nearest neighbor in the training set is larger than a threshold. This threshold is calibrated using only ID validation data, chosen so that the true positive rate on ID samples is 95% (TPR@95). The approach works best when the feature space is compact and well-separated. As a result, training with supervised contrastive loss instead of cross-entropy makes the embeddings more compact within each class and more separated across classes, enabling the KNN distance to perform better for OOD detection.

[2] ViM: Out-Of-Distribution with Virtual-logit Matching
CVPR 2022 Citations: 748 (as on date 08/16/2026) Category: OOD, Classification-based
Paper link

Most prior OOD detection methods rely on a single information source, either the feature, the logit, or the softmax probability. But logits and softmax probabilities are computed from a linear projection of the feature, so they discard information that lies outside this projection, information that can still be useful for detecting OOD samples. Feature-based methods like Mahalanobis, on the other hand, ignore class-dependent information that logits naturally capture, causing them to underperform on OOD samples that require fine-grained class distinctions.

In this paper, a method called Virtual-logit Matching (ViM) is proposed, which combines both feature-space and logit-space information into a single OOD score. After training a neural network, a principal subspace is estimated from the ID training features using PCA. For a given input, the residual (the feature component lying outside this principal subspace) is computed and its norm is rescaled by a precomputed constant into a virtual logit. This virtual logit is appended to the real class logits, and after softmax, the probability assigned to it is used as the OOD score. As a result, ViM captures information invisible to logit-based methods (via the residual) and information invisible to feature-based methods (via the real logits), and outperforms both feature-only and logit-only baselines across diverse OOD benchmarks.

[3] Towards Open Set Deep Networks
CVPR 2016 Citations: 2,599 (as on date 08/17/2026) Category: OSR, Classification-based
Paper link

Standard deep networks are closed-set: softmax forces every input into one of the known classes, even if it doesn't belong to any of them. This becomes a real problem in the open world, where models will inevitably encounter unknown categories, and can even be fooled into giving high-confidence predictions on meaningless or adversarial images. Simply thresholding softmax probability helps a little, but doesn't reliably catch these cases, since softmax always produces a normalized distribution over known classes regardless of how unrelated the input actually is.

The paper proposes OpenMax, a replacement for the softmax layer that can explicitly output an "unknown" class. For each class, a mean activation vector is computed from correctly classified training examples, using the penultimate layer (before softmax). The distances of these training examples from their class mean are used to fit a Weibull distribution per class, based on extreme value theory. At test time, the distance of a new input from each class mean is converted into a probability of being an outlier using this Weibull model, and this is used to discount the top few activation scores, most heavily for the highest ranked class. The discounted amount is redirected into a new "unknown" class score, and softmax is then computed over all scores together. If the unknown class wins, or if the top prediction's confidence is too low, the input is rejected as unknown. This lets the network detect open set and fooling inputs by recalibrating its existing scores.

Figure: OpenMax Algorithm [3].

[4] SSD: A Unified Framework for Self-Supervised Outlier Detection
ICLR 2021 Citations: 561 (as on date 08/18/2026) Category: OOD, Distance-based
Paper link

OOD detection techniques have mostly relied on models trained with fine-grained class labels for the in-distribution data. Collecting such labels at scale is expensive, which limits how widely these methods can be applied. Prior works with autoencoders have explored reconstruction error a s a metric to identify OOD, but they perform poorly, since reconstruction error doesn't reliably reflect the semantic features learned by the model.

To address this, SSD first trains a feature extractor using self-supervised contrastive learning, so that semantically similar images naturally end up close together in the feature space. Since there are no labels to define per-class centroids, k-means clustering is applied directly on the learned features to identify clusters. Mahalanobis distance to the nearest cluster's mean and covariance is then used as the outlier score, with the threshold set at TPR@95, calibrated on held-out ID data. The framework is further extended in two ways. When a few real OOD samples are available, their statistics are incorporated directly into the scoring function to improve detection. And when ID labels are available, the self-supervised loss is replaced with supervised contrastive loss, so the resulting clusters carry class-specific information, making the Mahalanobis distance to these clusters more effective for OOD detection.

Figure: SSD Algorithm [4].

[5] Delving into Out-of-Distribution Detection with Vision-Language Representations
NeurIPS 2022 Citations: 358 (as on date 08/20/2026) Category: OOD, Distance-based
Paper link

OOD detection methods often rely on a single modality (visual features), and do not fully leverage the rich information available in multimodal representations. Vision-language models (VLMs) such as CLIP align images with their textual descriptions during pretraining, producing context-rich representations that capture both visual and semantic information. These representations can therefore provide useful contextual information for OOD detection.

Maximum Concept Matching (MCM) is proposed, which is a zero-shot OOD detection method built on CLIP. Each ID class name is embedded using CLIP's text encoder to form a concept prototype. For a test image, its embedding is compared to each concept prototype using cosine similarity, giving one similarity score per ID class. These similarity scores are then passed through softmax, scaled by a temperature parameter, turning them into a probability distribution over the K classes. If one class's probability is significantly higher than the rest, the image matches that concept well and is likely ID. Conversely, if the probabilities are low and spread evenly across all classes, the image doesn't match any known concept and is likely OOD.

[6] Dream the Impossible: Outlier Imagination with Diffusion Models
NeurIPS 2023 Citations: 133 (as on date 08/20/2026) Category: OOD, Classification-based
Paper link

Prior work showed that training with auxiliary outlier data helps regularize a classifier's decision boundary to be more conservative around in-distribution (ID) data, but collecting real outlier datasets is labor-intensive and requires careful curation to avoid overlap with ID classes. Some previous works synthesized outliers in latent space and used them directly for training, but those features could not be visually inspected or understood. We may leverage diffusion models to generate images from text prompts, but it is hard to describe "what an outlier looks like" in words.

DREAM-OOD addresses this in two phases. In Phase 1, it trains an image feature encoder on only the ID data, using a contrastive loss that pulls each image's embedding toward its class's text token embedding from the text encoder. In Phase 2, it samples new embeddings from the low-likelihood boundary region of this learned space: for each ID point, it computes k-NN distance to find points near the boundary, draws several candidate embeddings from a Gaussian centered there, and keeps the one farthest from ID data (largest k-NN distance). Each sampled embedding is then decoded into pixel-space by feeding it into the diffusion model. These synthetic outlier images are used to regularize a classifier: during training, each batch contains both real ID images and synthetic OOD images, and both are passed through the same classifier backbone to get logits. The real ID images' logits are only used for the regular cross-entropy classification loss. In addition, a small 3-layer MLP head sits on top of the classifier's logits, computing a single energy score from them and passing it through a sigmoid; this head is trained with a binary cross-entropy loss, where ID images (real) are treated as the positive class and OOD images (synthetic) as the negative class. The total training loss combines the classification loss and this OOD regularization loss, weighted by a factor of Beta. At inference, a single forward pass on a test image gives both a class prediction (from the softmax output) and an OOD score (from the energy-MLP-sigmoid branch).
