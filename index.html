OOD/OSR Paper Notes

Summaries and feature comparison of OOD/OSR algorithms classified into 4 categories: (1) Classification-based (2) Distance-based (3) Density-based (4) Reconstrction-based

Papers

[1] Out-of-Distribution Detection with Deep Nearest Neighbors
ICML 2022 Citations: 1,121 (as on date 08/15/2026) Category: OOD, Distance-based
Paper link

Most prior distance-based OOD detection methods assume the ID feature embeddings for each class follow a Gaussian distribution, and use Mahalanobis distance to the nearest class centroid to flag OOD samples. But this assumption often doesn't hold in practice, which makes Mahalanobis distance unreliable for OOD detection. It's also computationally expensive, since it requires inverting a covariance matrix.

In this paper, a non-parametric approach leveraging KNN is proposed, which makes no assumption about the shape of the feature distribution. After training a neural network encoder, both training and test embeddings are L2-normalized, and a test sample is flagged as OOD if its distance to the k-th nearest neighbor in the training set is larger than a threshold. This threshold is calibrated using only ID validation data, chosen so that the true positive rate on ID samples is 95% (TPR@95). The approach works best when the feature space is compact and well-separated. As a result, training with supervised contrastive loss instead of cross-entropy makes the embeddings more compact within each class and more separated across classes, enabling the KNN distance to perform better for OOD detection.

[2] ViM: Out-Of-Distribution with Virtual-logit Matching
CVPR 2022 Citations: 748 (as on date 08/16/2026) Category: OOD, Classification-based
Paper link

Most prior OOD detection methods rely on a single information source, either the feature, the logit, or the softmax probability. But logits and softmax probabilities are computed from a linear projection of the feature, so they discard information that lies outside this projection, information that can still be useful for detecting OOD samples. Feature-based methods like Mahalanobis, on the other hand, ignore class-dependent information that logits naturally capture, causing them to underperform on OOD samples that require fine-grained class distinctions.

In this paper, a method called Virtual-logit Matching (ViM) is proposed, which combines both feature-space and logit-space information into a single OOD score. After training a neural network, a principal subspace is estimated from the ID training features using PCA. For a given input, the residual (the feature component lying outside this principal subspace) is computed and its norm is rescaled by a precomputed constant into a virtual logit. This virtual logit is appended to the real class logits, and after softmax, the probability assigned to it is used as the OOD score. As a result, ViM captures information invisible to logit-based methods (via the residual) and information invisible to feature-based methods (via the real logits), and outperforms both feature-only and logit-only baselines across diverse OOD benchmarks.

[3] Towards Open Set Deep Networks
CVPR 2016 Citations: 2,599 (as on date 08/17/2026) Category: OSR, Classification-based
Paper link

Standard deep networks are closed-set: softmax forces every input into one of the known classes, even if it doesn't belong to any of them. This becomes a real problem in the open world, where models will inevitably encounter unknown categories, and can even be fooled into giving high-confidence predictions on meaningless or adversarial images. Simply thresholding softmax probability helps a little, but doesn't reliably catch these cases, since softmax always produces a normalized distribution over known classes regardless of how unrelated the input actually is.

The paper proposes OpenMax, a replacement for the softmax layer that can explicitly output an "unknown" class. For each class, a mean activation vector is computed from correctly classified training examples, using the penultimate layer (before softmax). The distances of these training examples from their class mean are used to fit a Weibull distribution per class, based on extreme value theory. At test time, the distance of a new input from each class mean is converted into a probability of being an outlier using this Weibull model, and this is used to discount the top few activation scores, most heavily for the highest ranked class. The discounted amount is redirected into a new "unknown" class score, and softmax is then computed over all scores together. If the unknown class wins, or if the top prediction's confidence is too low, the input is rejected as unknown. This lets the network detect open set and fooling inputs by recalibrating its existing scores.
